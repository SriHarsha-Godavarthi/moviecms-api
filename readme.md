This is Rest Api service Build for Handling CRUD operations of creatiion and management on CMS system for OTT platform called MovieFlix

Tech Stack:
FASTAPI
Pydantic Models

Features Included:
ORM(Object Relational Mapper)
Proper looging (Structure of log should start with timestamp, path,HttpMethodInvoked,logrequiredFieldsfromPayload)
Request and Response Validation(using Pydantic Models)
Modular Reusable Code using OOPS concepts
Create a Docker Image that was secure and doesn't have any vulnerabilities
Implement Dependency Injetion, JWT middleware Authentication except for login,healthcheck, signup routes
